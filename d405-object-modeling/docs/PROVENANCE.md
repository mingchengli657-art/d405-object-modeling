# 提取来源与验证记录

## 来源和保留范围

来源是 Piper_Fetch 下的 `object_modeling`，原目录未修改。

保留：`src/object_modeling/`、原有五项算法测试、Python 安装配置、默认 ChArUco 配置、采集/建模/检查脚本。

排除：约 1.8 GB 完整 datasets、`__pycache__`、`*.egg-info`、重复的转盘配置、旧转盘命名启动脚本。原 README 存于 `docs/ORIGINAL_README.md`，仅供追溯，当前用法以根目录 README 为准。

示例来自 `datasets/object_003` 的 000000–000007 八组真实彩色/深度图及对应 CSV 行，保留相机内参，另写子集 manifest；没有缩放图像或改动位姿。此子集用于检查流程，不代表完整扫描。没有混入其他物体或旧模型版本。

## 为独立运行所做的修改

- 依赖改为带 ChArUco 的 opencv-contrib-python，并限制原工程兼容的 OpenCV 4.5.x / NumPy 1.x 范围；基线 Python 3.10。
- 保留安装兼容入口 setup.py，与 pyproject.toml 的依赖、版本和测试 extras 对齐。
- 启动脚本取消自动读取个人比赛依赖文件和固定 ROS 路径；要求操作者显式 source ROS 环境。
- 参数环境变量更名为 OBJECT_MODELING_CONFIG，合并转盘命名脚本到 capture_d405.sh。
- 采集拒绝非空目录，避免旧 poses.csv 和图像被覆盖；达到帧数后退出，拒绝帧预览也支持 q 退出。
- 检查图像写入是否成功，拒绝零时间戳，并记录采集板参数。
- 网格失败、过滤后无点、体素尺寸非法时明确报错，不再为失败的新模型写出成功摘要。
- 模型元数据附上建模配置；验证器的 usable_frames 计数检查实际配对图像，避免仅凭 CSV 误报。
- 增加安装、数据格式、坐标、算法限制、上传说明，添加 GitHub Actions。

融合数学、体素支持度、背景清理和凸包算法沿用原实现。没有新增 TSDF、Poisson、畸变校正或自动机器人控制。
